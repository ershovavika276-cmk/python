## Введение

Python – это высокоуровневый язык программирования, который был разработан в конце 1980-х годов. Его разработчик, Гвидо ван Россум, вложил в основу языка простоту и читабельность кода, что позволяет использовать Python для быстрой и эффективной разработки.

## Особенности языка
* Читаемость и минималистичный синтаксис: Код на Python часто похож на обычный английский язык. Вместо фигурных скобок {} для группировки блоков используются отступы (индентация), что принудительно делает код аккуратным и понятным.
 * Интерпретируемость: Код выполняется строкой за строкой без предварительной компиляции в бинарный файл, что ускоряет процесс отладки и разработки.
 * Динамическая типизация: Не нужно вручную объявлять типы переменных — интерпретатор сам определяет их во время выполнения.
 * Богатая экосистема библиотеки (Batteries Included): В стандартную библиотеку и реестр PyPI входят сотни тысяч готовых модулей для работы с сетью, базами данных, математикой, графикой и машинным обучением.
 * Кроссплатформенность: Код, написанный на одной ОС (Linux, Windows, macOS), запускается на любой другой без изменений (при наличии интерпретатора).

## Структуры данных языка Python
1. Списки(list) – упорядоченные коллекции элементов, которые могут быть любого типа данных. Доступ к элементам списка осуществляется по индексу.
    [1, 2, 3] или list()
2. Кортежи(tuple) – упорядоченные коллекции элементов, которые могут быть любого типа данных, но не могут быть изменены после создания.
    (1, 2, 3) или tuple()
3. Словари(dict) – неупорядоченные коллекции пар "ключ-значение". Доступ к значениям словаря осуществляется по ключу.
   {'key': 'value'} или dict()
4. Множества(set / frozenset) – неупорядоченные коллекции уникальных элементов.
   {1, 2, 3} или set(); неизменяемый вариант — frozenset()
5. Файлы – структура данных, которая используется для чтения и записи информации на диске.

## Функции языка Python
Встроенные функции Python используются для решения различных задач.

–  print() – для вывода текста или переменных на консоль.

– input() – запрашивает ввод данных от пользователя.

– len() – возвращает длину объекта (например, строки, списка или кортежа).

– type() –  возвращает тип объекта.

– range() – создает последовательность чисел.

– int(), float(), str(), bool() – используются для преобразования объектов в целые числа, числа с плавающей запятой, строки и булевые значения соответственно.

– sum() – суммирует элементы последовательности чисел.

– sorted() – сортирует элементы последовательности.

– max() и min() – возвращают максимальный и минимальный элементы последовательности.

– abs() – возвращает абсолютное значение числа.
